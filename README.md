# DX 602 — Homework

My completed homework notebooks for BU CDS DX 602.

    week-01/homework.ipynb
    week-02/homework.ipynb
    ...

Each notebook is named `homework.ipynb` because Gradescope requires that exact
filename on upload.

## Running the notebooks

No third-party packages are required — the notebooks use only the Python
standard library. You need Python 3.14 and a Jupyter kernel.

### 1. Create the environment

macOS / Linux:

    python3.14 -m venv .venv
    source .venv/bin/activate
    pip install ipykernel

Windows:

    py -3.14 -m venv .venv
    .venv\Scripts\activate
    pip install ipykernel

If the interpreter is missing, install it with `brew install python@3.14` on
macOS, `winget install Python.Python.3.14` on Windows, or your distribution's
package manager on Linux. In PowerShell, activate with
`.venv\Scripts\Activate.ps1`; if that is blocked, run
`Set-ExecutionPolicy -Scope Process RemoteSigned` first.

### 2. Run in VS Code

VS Code starts and stops the kernel for you — no server to launch or shut down.

1. Open the notebook, e.g. `homework/week-01/homework.ipynb`.
2. Click the kernel picker at the top right of the notebook.
3. Choose **Select Another Kernel… → Python Environments…**, then pick
   `.venv (Python 3.14.7)`.
4. Run cells with **Shift+Enter**, or **Run All** from the toolbar.

The kernel starts on the first cell you run. Use **Restart** in the toolbar to
reset it, and just close the notebook when you are done.

### Alternative: JupyterLab in the browser

With the environment activated:

    pip install jupyterlab
    jupyter lab

Press **Ctrl+C** twice in that terminal to shut the server down, then
`deactivate` to leave the virtual environment.

The `.venv/` directory is gitignored, so it is never committed.

## Before submitting

1. Restart the kernel and run all cells.
2. Confirm every cell has output and no errors.
3. Save, then upload `homework.ipynb` to Gradescope via Blackboard.
